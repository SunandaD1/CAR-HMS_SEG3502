# Gestion des randonnées (hikemanagement)

**Classification :** Cœur

Cycle de vie d'une randonnée (ouverte, complète, fermée, annulée, terminée), règles de création (saison du sentier, date limite d'inscription, certification de l'organisateur) et enregistrement de l'utilisateur qui effectue chaque étape.

**Cas d'utilisation :** Parcourir les randonnées, Créer une randonnée, Annuler une randonnée, Fermer une randonnée
